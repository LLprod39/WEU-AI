О платформе

Не просто чат.
Всё в одном окне.

WEU AI — это веб-приложение для DevOps-команд. Открываешь браузер — и у тебя сразу чат с ИИ, список агентов, таск-трекер, SSH-терминалы и база знаний. ИИ видит твои серверы и задачи, умеет подключаться по SSH, запускать сценарии и формировать отчёты. Никакой установки CLI — только браузер.

Протокол
Кому подходит
  • engineering
    DevOps / SRE
    Агент сам соберёт логи, предложит фикс и откроет SSH-сессию. Ты только смотришь и подтверждаешь нужные шаги.
  • admin_panel_settings
    Системные администраторы
    Все сервера в одном месте. История действий, зашифрованные пароли, воспроизводимые сценарии.
  • groups
    Тимлиды
    Плейбуки, логи, роли. Стандартизируй процессы и всегда знай, кто что запустил и с каким результатом.
Возможности

Всё что нужно.
Ничего лишнего.

Шесть ключевых модулей. Каждый — решение конкретной проблемы, без абстракций.

chat

Чат с ИИ

Задаёшь вопрос в браузере, получаешь ответ с планом. ИИ знает про твои серверы, задачи, историю работы — не нужно объяснять контекст с нуля.

bolt Gemini, Grok — выбор провайдера
account_tree

Агенты и воркфлоу

Описываешь задачу — агент строит шаги, запускает их и формирует отчёт. Реальные кейсы: деплой Docker, проверка дисков, очистка логов, бэкапы.

bolt Ralph, Cursor, Claude Code, ReAct
dns

Серверы и SSH

Все SSH-подключения в одном месте. Полноценный браузерный терминал (xterm.js), мульти-вкладки, зашифрованные пароли — подключаешься в два клика.

bolt AES-256 шифрование учётных данных
task_alt

Таски и проекты

Встроенный трекер: проекты, спринты, подзадачи, метки. Задачи связаны с агентами — настроил один раз, дальше запускается автоматически.

bolt Интеграция с Jira
library_books

База знаний (RAG)

Загружаешь runbook'и, регламенты, документацию — ИИ подтягивает нужные фрагменты при ответах. Актуальный контекст без copy-paste.

bolt Qdrant vector search
visibility

Контроль, не слепая вера

Видишь каждый шаг агента в реальном времени. Можешь подтвердить или остановить. Опасные системные команды блокируются автоматически.

bolt rm -rf, mkfs, dd — заблокированы
