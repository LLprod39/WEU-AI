# Выбор и настройка моделей

WEU AI поддерживает несколько LLM-провайдеров. Модели настраиваются отдельно для чата, агентов и RAG.

---

## Провайдеры

| Провайдер | API ключ | Статус |
|-----------|----------|--------|
| **Google Gemini** | `GEMINI_API_KEY` | ✅ Полная поддержка |
| **xAI Grok** | `GROK_API_KEY` | ✅ Полная поддержка |
| **Cursor (CLI)** | `CURSOR_API_KEY` | ✅ Принудительно `auto` |
| **Claude Code (CLI)** | через Anthropic CLI | ✅ Через subprocess |

---

## Конфигурация через UI

**Настройки → Модели** — раздел в веб-интерфейсе.

Каждый провайдер имеет три независимые модели:

| Назначение | Описание |
|------------|----------|
| **Chat model** | Для обычного чата (`/chat/`) |
| **Agent model** | Для ReAct-оркестратора и агентов |
| **RAG model** | Для обработки запросов с базой знаний |
| **Default provider** | Провайдер по умолчанию при открытии чата |

---

## Конфигурация через файл `.model_config.json`

Файл в корне проекта, изменяется через UI или вручную:

```json
{
  "chat_model_gemini":  "gemini-2.0-flash-exp",
  "agent_model_gemini": "gemini-2.0-flash-exp",
  "rag_model_gemini":   "gemini-1.5-flash",
  "chat_model_grok":    "grok-beta",
  "agent_model_grok":   "grok-beta",
  "rag_model_grok":     "grok-beta",
  "default_provider":   "gemini"
}
```

> **Примечание:** Файл перезаписывается при сохранении настроек через UI.

## Рекомендуемые модели Gemini

| Задача | Модель | Причина |
|--------|--------|---------|
| Чат (скорость) | `gemini-2.0-flash-exp` | Быстрый, дешёвый |
| Агент (качество) | `gemini-2.0-flash-exp` | Баланс скорость/качество |
| RAG (экономия) | `gemini-1.5-flash` | Достаточно для retrieval |
| Сложные задачи | `gemini-1.5-pro` | Максимальный контекст |

---

## Рекомендуемые модели Grok

| Задача | Модель |
|--------|--------|
| Все задачи | `grok-beta` |
| Новейший | `grok-2-latest` (если доступен) |

---

## Курсор и Claude Code

Модели для CLI-агентов устанавливаются иначе:

- **Cursor**: Модель всегда принудительно `auto` — это ограничение Cursor CLI. Пользователь не может изменить модель через UI.
- **Claude Code**: Использует модель из Anthropic CLI конфигурации. Настраивается в CLI, не через WEU AI UI.

---

## Переключение провайдера в чате

В интерфейсе чата (`/chat/`) есть выпадающий список провайдеров и моделей:

1. Выбери **Gemini** или **Grok** в дропдауне
2. Список моделей обновится автоматически
3. Выбор сохраняется в сессии браузера

---

## Добавление нового провайдера (для разработчиков)

Новый LLM-провайдер добавляется через `app/core/llm.py`:

```python
class YourProvider(LLMProvider):
    def __init__(self, api_key: str):
        ...

    async def chat(self, messages: list, model: str, stream: bool = True):
        ...
```

Затем зарегистрировать в `ModelManager` в `app/core/model_config.py`.

## Устранение проблем

**Ошибка "No API key configured":**
```
Проверь .env: GEMINI_API_KEY или GROK_API_KEY должны быть заполнены.
Перезапусти сервер после изменения .env.
```

**Модели не обновляются в UI:**
```
Нажми F5 или очисти кэш браузера.
Проверь: Настройки → Модели → Сохранить.
```

**Медленные ответы:**
```
Переключись на gemini-2.0-flash-exp или grok-beta.
Проверь сетевое соединение до API.
```
