# Правила игры (Merge 2048 Drop)

## Выбор колонки и падение плитки

- **Игрок выбирает колонку** — тап по верхней части поля (по зоне колонки). Колонка определяется по координате нажатия.
- **Активная плитка** имеет значение 2, 4, 8 и т.д. (степени двойки). Она «сбрасывается» в выбранную колонку.
- **Падение вниз** — плитка падает по выбранной колонке и занимает **самый нижний пустой слот** в этой колонке (первая свободная ячейка сверху вниз, либо нижний ряд, если колонка пуста).

## Слияние (merge)

- **При приземлении** проверяется соседство по вертикали и горизонтали с другими плитками.
- Если приземлившаяся плитка **соприкасается с плиткой такого же значения** (по вертикали или горизонтали), запускается **merge-цепочка**.
- **Merge-цепочка** работает по принципу «слияния комков»: все связанные плитки одинакового значения, образующие связную область (по вертикали/горизонтали), сливаются в одну плитку с удвоенным значением. Цепочка может продолжаться, если новая плитка снова соприкасается с такой же — и так до тех пор, пока не останется пар для слияния.

## Итог

1. Тап по верхней части поля → выбор колонки.
2. Активная плитка падает вниз → занимает нижний пустой слот в колонке.
3. При контакте с плиткой того же значения по вертикали/горизонтали → запускается merge-цепочка (слияние комков).
