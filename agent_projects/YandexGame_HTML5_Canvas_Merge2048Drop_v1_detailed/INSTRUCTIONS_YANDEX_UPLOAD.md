# Инструкция: загрузка игры в Яндекс Игры

## 1. Сборка архива

В корне проекта выполните:

```bash
npm run pack
```

В результате будет создан файл **dist.zip**.

---

## 2. Создание игры в консоли

1. Откройте [консоль Яндекс Игр](https://console.yandex.ru/games/).
2. Войдите в аккаунт Яндекса.
3. Нажмите **«Создать игру»** (или аналогичную кнопку).
4. Выберите тип проекта (HTML5/Canvas и т.п., если требуется).

---

## 3. Загрузка архива

1. В карточке созданной игры найдите раздел загрузки билда (файла игры).
2. Загрузите файл **dist.zip**, полученный на шаге 1.
3. Дождитесь окончания загрузки и обработки.

---

## 4. Заполнение карточки игры

Заполните обязательные поля:

- **Название** — название игры.
- **Описание** — краткое описание игры для каталога.
- **Скриншоты** — загрузите скриншоты игры (по требованиям платформы).
- **Иконка** — загрузите иконку приложения (обычно квадратная, указанного размера).

Сохраните изменения.

---

## 5. Отправка на модерацию

1. Убедитесь, что все обязательные поля заполнены и билд загружен.
2. Нажмите **«Отправить на модерацию»** (или аналогичную кнопку).
3. Дождитесь проверки; статус и возможные замечания будут в консоли Яндекс Игр.
