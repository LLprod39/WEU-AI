# Описание игры

Merge-игра в стиле 2048 Drop. Цель — набрать как можно больше очков и улучшить свой рекорд.

## Управление

- **Тап по колонке** — выбор колонки, в которую падает активная плитка. Тап по верхней части игрового поля (по зоне колонки).

## Основные возможности

- **Продолжить** — возобновить последнюю партию с сохранённого состояния поля и счёта.
- **Рекорд (Best)** — сохраняемый лучший счёт за сессию.
- **Отмена хода за рекламу (rewarded undo)** — после просмотра рекламы можно отменить ход и вернуть поле к предыдущему состоянию.
- **Очистить ряд за рекламу (rewarded clear row)** — после просмотра рекламы можно очистить один ряд; использование ограничено по времени (кулдаун).
