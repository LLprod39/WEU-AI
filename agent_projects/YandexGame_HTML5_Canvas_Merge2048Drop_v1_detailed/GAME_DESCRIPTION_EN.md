# Game Description

A merge-style game (2048 Drop). The goal is to score as many points as possible and beat your best record.

## Controls

- **Tap on a column** — choose the column where the active tile drops. Tap on the top area of the playfield (column zone).

## Main Features

- **Continue** — resume the last game from the saved board and score state.
- **Best score** — saved high score for the session.
- **Rewarded undo** — after watching an ad, you can undo the last move and restore the previous board state.
- **Rewarded clear row** — after watching an ad, you can clear one row; usage is limited by a cooldown.
