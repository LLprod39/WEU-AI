# Dodge & Collect

An arcade “dodge and collect” game: control your character on screen, avoid falling obstacles, and pick up bonuses. Difficulty ramps up over time—more objects and higher speed—so quick reflexes and precise control are key.

The game runs in the browser with no install required and stays fully playable offline after the first load. Suited for short sessions and chasing high scores.

## Features

- **Second chance** — after game over you can continue the run (when ad reward is available via Yandex SDK).
- **Best score** — your high score is saved locally and shown in the UI.
- **Smooth controls** — responsive drag and touch input with no jitter.

## Controls

- **Drag** — press and hold on the screen (mouse or finger) and move in the direction you want; the character follows the pointer.
- **Touch** — on touch devices, use touch and drag within the game area to move.

A single pointer (finger or cursor): small movement is treated as a tap; once you drag past the threshold, the character follows the pointer.

## Registration and platform

The game **does not require registration**—you can start playing immediately. When run inside Yandex Games (Yandex SDK), extra features are available: rewarded ads for continue (second chance), leaderboards for best score, and other SDK features when integrated in the build.
