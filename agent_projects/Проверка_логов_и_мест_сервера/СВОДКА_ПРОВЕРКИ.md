## Рекомендации по устранению

### Критические

1. **Postfix (mydomain)**  
   - Настроить `mydomain` в конфигурации Postfix (например в `main.cf`: `mydomain = your.domain` или отключить sendmail в cron, если почта не используется).  
   - Проверить: `sudo postconf mydomain` и при необходимости задать значение.

2. **Диск Docker (/dev/loop0)**  
   - Освободить место в Docker: `docker system prune -a` (осторожно — удалит неиспользуемые образы/контейнеры/сети).  
   - Увеличить размер виртуального диска Docker Desktop (Settings → Resources → Disk image size) или перенести данные на другой диск.

3. **Диск C: (94%)**  
   - Перенести тяжёлые каталоги (проекты, Docker, кэши) на D: или другой раздел.  
   - Очистить временные файлы, кэш браузеров, старые сборки, `node_modules` дубликаты.  
   - Настроить ротацию логов (в т.ч. Playwright/Django), чтобы логи не раздували диск.

4. **Скачки времени (Time jumped backwards)**  
   - Синхронизировать время WSL/Windows (NTP).  
   - Проверить отключение/включение гибернации и смену часового пояса — при необходимости перезапустить WSL.

### Предупреждения (по приоритету)

5. **favicon.ico 404**  
   - Добавить в проект статический файл `favicon.ico` и подключить его в базовом шаблоне (или отдать через nginx/Django static).

6. **Skills: 400 и TypeError на /skills/**  
   - Разобрать запрос к `/skills/api/skills/catalog/install/` (тело, заголовки) и исправить валидацию на бэкенде.  
   - Исправить JS на странице `/skills/`: перед присвоением `onclick` проверять, что элемент существует (не null).

7. **Tailwind в production**  
   - Собрать CSS через PostCSS/Tailwind CLI и отдавать статический CSS вместо `cdn.tailwindcss.com`.

8. **Docker addgroup**  
   - Убрать лишние аргументы в скриптах добавления группы `docker` или добавить проверку «группа уже существует», чтобы не вызывать addgroup с двумя аргументами.
