## 2024-05-14 - Mobile Icon Accessibility
**Learning:** In the mobile UI templates (like `base.html` and `knowledge_base.html`), several header and floating action buttons use `material-icons-round` without accompanying text. This renders them inaccessible to screen readers as they lack both an `aria-label` and `aria-hidden="true"` on the icon itself. The application mixes standard Django templates with vanilla JS that inserts HTML strings directly into the DOM (e.g. `mobile-kb-doc-delete`).
**Action:** Always add descriptive `aria-label` attributes in Russian (matching the UI context) to the parent `<button>`, and `aria-hidden="true"` to the inner `<span class="material-icons-round">`. Remember to also update dynamically generated HTML strings in the `<script>` blocks of templates.
