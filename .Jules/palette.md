## 2023-10-27 - Icon-Only Button Accessibility Pattern in Django Templates
**Learning:** Icon-only buttons within this application's custom Django UI (specifically those using `<span class="material-icons-round">` inside `<button>`) frequently lack semantic descriptions. Since the visual meaning is conveyed exclusively through an icon, screen readers announce these buttons as empty or just read the icon font's literal text (e.g., "send" or "content_copy") if not hidden, confusing users.
**Action:** When creating or reviewing icon-only buttons in the project's templates, always provide a descriptive `aria-label` attribute on the outer `<button>` element. Additionally, append `aria-hidden="true"` to the inner `<span class="material-icons-round">` or `<svg>` tag to prevent screen readers from redundantly or incorrectly announcing the icon content itself.
