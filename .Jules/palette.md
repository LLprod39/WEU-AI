## 2026-05-19 - ARIA Labels on Mobile Chat Action Buttons
**Learning:** In the mobile web app (`core_ui/templates/mobile/chat.html`), several key icon-only action buttons (like history, new chat, close drawer, RAG toggle, and send message) were missing `aria-label` attributes. Additionally, the nested `<span class="material-icons-round">` elements lacked `aria-hidden="true"`, causing screen readers to potentially read the text content of the icon font ligature (e.g. "history", "add", "close", "storage", "send") instead of the action meaning.
**Action:** Always ensure that icon-only buttons using Material Icons have a descriptive `aria-label` on the parent `<button>` and that the inner `<span class="material-icons-round">` has `aria-hidden="true"` so that screen readers announce the intended action, not the ligature text.
