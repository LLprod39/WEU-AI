## 2024-05-24 - Missing ARIA labels on Mobile Icon-only Buttons
**Learning:** Found a widespread pattern where icon-only buttons across mobile templates (`core_ui/templates/mobile_app.html`, `chat.html`, `base.html`, `knowledge_base.html`) lacked `aria-label`s, rendering them completely inaccessible to screen readers. Often these used just a `title` attribute or a child `<span class="material-icons-round">` that screen readers would incorrectly attempt to read as the text itself.
**Action:** Consistently added descriptive `aria-label` attributes to the parent `<button>` tags and added `aria-hidden="true"` to the inner `<span class="material-icons-round">` tags. This ensures screen readers announce the button's intended function correctly instead of the icon font ligature.
